# Registro de cambios

## Organización y seguridad
- Reestructura del proyecto para distribución y desarrollo.
- Exclusión de datos locales, entorno virtual y artefactos generados.
- Añadidas pruebas de consistencia del registro de herramientas.
- Eliminadas referencias a versiones anteriores.

## Fiabilidad
- Verificación posterior a acciones reales.
- Recuperación adaptativa tras fallos verificables.
- Streaming seguro sin afirmaciones simuladas.
- Persistencia de evidencias en modo texto y voz.

## Plataforma
- Diagnóstico de GPU y selección compatible del runtime de Whisper.
- Soporte para control de ventanas y escritorio.
- Interfaz gráfica con actividad, memoria y configuración.
